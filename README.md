## 🚀 Uso y Scripts Útiles

### Compilación en C++ (`compile.sh`)
Para compilar y probar rápidamente cualquier solución en C++ con un archivo `input.txt` / `in`:
```bash
cd Competitive
./compile.sh
```

### Sincronización Git (`push.sh`)
Para hacer stage, commit y push con mensajes rápidos y notificaciones de escritorio:
```bash
./push.sh
# O para archivos específicos:
./push.sh Competitive/ Python/
```
